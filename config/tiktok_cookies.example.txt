# Пример для TikTok. Скопируй в config/tiktok_cookies.txt и подставь РЕАЛЬНЫЕ
# значения из браузера (DevTools → Application → Cookies → tiktok.com), либо
# экспортируй расширением «Get cookies.txt». Проще: [tiktok] cookies_from_browser="chrome".
#
# Формат (TAB-разделённый, 7 полей):
#   domain   include_subdomains   path   secure   expiry   name   value
# Строки с префиксом #HttpOnly_ — тоже реальные куки (не комментарий).
# Парсер берёт куки домена *tiktok* (поля name/value), остальное игнорирует.
#
# Ключевые куки: ttwid (устройство), msToken (подпись API), tt_csrf_token,
# tt_chain_token; sessionid/sid_guard — только если залогинен.
